Waveshare's 3D model of the board goes here and is not included in this repository.

Download `ESP32-S3-Touch-AMOLED-1.8-3D.zip` from the resources section of the
[Waveshare wiki](https://www.waveshare.com/wiki/ESP32-S3-Touch-AMOLED-1.8) and unzip
`ESP32-S3-Touch-AMOLED-1.8-3D.stp` into this folder. `scripts/import_step.py` imports it.
